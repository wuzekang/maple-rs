## 2. 冲刺状态分析

### 2.1 CDashTrigger 类实现

通过分析发现了 CDashTrigger 类的核心实现：

- **虚函数表地址**: 0xb54da4 (??_7CDashTrigger@@6B@)
- **虚函数表内容**: 0x6de9e0

该类主要负责处理角色的冲刺触发逻辑。

### 2.2 冲刺相关全局变量

发现了以下关键的冲刺相关全局变量：

| 变量名 | 地址 | 功能说明 |
|--------|------|----------|
| CTS_Dash_Speed | 0xc6ca00 | 冲刺速度配置 |
| CTS_Dash_Jump | 0xc6ca10 | 冲刺跳跃配置 |
| CTS_Dash_Speed_0 | 0xc6de4c | 冲刺速度备用配置 |
| CTS_Dash_Jump_0 | 0xc6ded0 | 冲刺跳跃备用配置 |

### 2.3 冲刺物理计算

根据全局变量分析，冲刺状态的物理计算包含：

1. **冲刺速度**: 基础值为 0x8 (8 像素/帧)
2. **冲刺跳跃**: 基础值为 0x10 (16 像素/帧)
3. **配置结构**: 每个配置占用 16 字节，包含速度、跳跃、持续时间等参数

### 2.4 CUserLocal::RUSH 结构

发现了 CUserLocal 类中的 RUSH 结构体，用于管理冲刺状态：

- **RUSHELEM 结构**: 存储冲刺元素的详细信息
- **内存管理**: 使用 ZRecyclableAvBuffer 进行内存管理
- **实例地址**: 0xc6875c

## 3. 击飞效果分析

### 3.1 物理参数发现

通过字符串搜索发现了以下物理相关参数：

- **psdJump**: 伪跳跃参数，用于击飞效果计算
- **psdSpeed**: 伪速度参数，影响击飞的水平移动
- **incJump**: 跳跃增量参数
- **incSpeed**: 速度增量参数

### 3.2 击飞状态管理

击飞效果的实现通过以下机制管理：

1. **速度计算**: 基于 psdSpeed 和 incSpeed 计算水平击飞速度
2. **跳跃计算**: 基于 psdJump 和 incJump 计算垂直击飞速度
3. **持续时间**: 通过内部计时器控制击飞持续时间

## 4. 传送技能分析

### 4.1 位置处理机制

传送技能的实现涉及以下组件：

1. **CVecCtrl 系统**: 负责位置和移动控制
2. **COpenGatePool**: 管理传送门的创建和销毁
3. **OPENGATE 结构**: 存储传送门的位置和属性信息

### 4.2 传送门管理

发现了完整的传送门管理系统：

- **创建函数**: OnOpenGateCreated (0x68bfd0)
- **销毁函数**: OnOpenGateRemoved (0x68b780)
- **进入检测**: TryEnterOpenGate (0x689860)
- **更新函数**: Update (0x689e00)

### 4.3 传送逻辑

传送技能的核心逻辑：

1. **位置验证**: 检查目标位置是否有效
2. **碰撞检测**: 确保传送位置不会发生碰撞
3. **状态同步**: 更新角色位置并同步到服务器

## 6. 特殊移动状态管理

### 6.1 状态枚举

基于分析发现的移动状态类型：

1. **普通移动**: 基础的左右移动
2. **跳跃状态**: 包含重力计算的跳跃
3. **冲刺状态**: 高速移动状态
4. **击飞状态**: 被攻击后的强制移动
5. **传送状态**: 瞬间位置变化
6. **悬浮状态**: 特殊技能的悬浮效果

### 6.2 状态转换机制

特殊移动状态的转换通过以下方式管理：

1. **优先级系统**: 不同状态有不同的优先级
2. **时间控制**: 状态持续时间的精确控制
3. **中断机制**: 高优先级状态可以中断低优先级状态
4. **恢复机制**: 状态结束后恢复到默认状态

## 7. 物理计算细节

### 7.1 重力系统

虽然没有直接找到重力常量，但通过分析可以推断：

3. **地面检测**: 确定角色是否在地面上

### 7.2 碰撞检测

## 9. 结论

MapleStory 的特殊移动状态系统是一个复杂而精密的物理引擎，包含：

1. **多层次的类继承结构**: 从基础的 CVecCtrl 到特定的 CVecCtrlUser
2. **完整的状态管理机制**: 包括状态转换、优先级处理、时间控制
3. **精确的物理计算**: 重力、速度、加速度的精确计算
4. **高效的内存管理**: 使用 ZRecyclableAvBuffer 进行内存优化
5. **模块化的设计**: 不同类型的移动对象有独立的控制类

这个系统为 MapleStory 提供了流畅的移动体验和丰富的特殊移动效果，是游戏物理引擎的核心组成部分。
